# Opdracht Quiz Component

Een educatieve quiz applicatie (quiz component) ontwikkeld voor Little Miss Robot met React.

## Technologie Stack

- **React** 
- **Zustand** (voor State management)
- **Vite** (Build tool) 

De applicatie is gehost op Netlify met continous deployment en zichtbaar op `https://swnzquizcomponent.netlify.app`

## Functionaliteit

### Werkend
- Vragen via API
- Het selecteren van een antwoord
- Antwoord verzenden en validatie
- Visuele feedback (correct/incorrect)
- Naar volgende vraag navigeren
- Timer per vraag

### Extra's
- Start pagina zodat bij het openen niet automatisch alle timers van start gaan
- Navigatie voor codebase en PVA pdf
- State management
- Modal voor game-over en gameoverview
- Total timer -> tijd per x-vragen opgeteld + 60 sec 

### Niet werkende onderdelen
- Knoppen in linker paneel (disabled)
- "Geef me een tip" functionaliteit (disabled)
